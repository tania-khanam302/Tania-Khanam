# Tania Khanam – MERN Portfolio

A modern personal portfolio website built with the MERN Stack.  
This project showcases my skills, projects, education, experience, and professional information.

## 🚀 About The Project

This is a full-stack personal portfolio website developed using React, Node.js, Express.js, and MongoDB.

The portfolio content is dynamically managed through an Admin Dashboard.

## ✨ Features

### 🌐 Public Website

- Home page
- About section
- Dynamic skills section
- Education and experience section
- Dynamic project section
- Contact form
- Portfolio page
- Project pagination
- Responsive design

### 🔐 Admin Dashboard

- Admin login
- Protected admin routes
- Dashboard statistics
- Project management
- Skills management
- Education & experience management
- Contact message management
- Add, edit and delete content
- Admin logout

## 💻 Technologies Used

### Frontend

- React.js
- Vite
- React Router
- CSS
- Font Awesome

### Backend

- Node.js
- Express.js
- MongoDB
- Mongoose
- CORS
- dotenv
